请从零开发一个动态虚拟表格采集器，把本地模拟网站的数据存入 SQLite，并为每个单元格保留真实截图证据。使用 Windows 原生 Python 3.12、Playwright/Chromium；模拟站点用普通 HTML/JavaScript。站点、采集器和测试均需交付，没有外部附件。

1. 模拟表格至少200行、12列，同时横纵虚拟滚动并复用 DOM 节点，只渲染视口附近内容。具有冻结编号列、两层表头和不同父级下的同名列；页面公开记录总数、列数、数据版本、加载状态及每次重绘递增的视图序号。
2. 采集器只接收 URL 和配置，通过滚动、点击、可见 DOM 与截图采集，不能读接口响应、前端私有数据或测试答案。用“版本+记录编号+完整表头路径”识别单元格，采齐所有行列后才能完成；临时空白或重复行不能当作结束。
3. 每格原文关联截图、图片摘要和像素区域，能离线打开图片并高亮。读取文字到截图之间若发生重绘，必须丢弃本次观察并重取，不能文字和图片各来自一个时刻；图片被修改或缺失时须能检出。
4. 采集中切换数据版本，不能拼接新旧数据。进程中断后允许复核续采或重采，但不能把半成品当成果，也不能破坏上一批完整结果；持续不稳定时应在有限重试后明确失败。

自建已知答案，逐格核对结果，重点测试节点复用、截图前重绘、采集中换版本，以及图片已写入但数据库未提交时中断。测试可读取答案，采集器不得读取。交付运行入口、离线证据查看页、自动化测试和 Windows 说明，写清实测结果及未完成项，不使用 Docker。
